# 6. データと個人情報

管理職や情報担当の先生に説明するときに使ってください。

## どこに何が保存されるか
| データ | 置き場所 |
|---|---|
| 名簿（部員ID・氏名・学年・組・メールアドレス・在籍）、日誌（予定・やったこと・次回やること・出欠）、コメント、既読、締切・目標、テーマと所属 | **ハコ日誌DB**（先生だけの場所に置くスプレッドシート） |
| 活動日・行事・時間・場所 | **活動予定表**（部員と使うフォルダ。個人情報は書かない） |
| アプリの設定（アプリ名・団体名・色・リンク） | アプリのスクリプト プロパティ |

- **作者や外部のサーバーには、データを送りません。** 動作は、学校の Google の環境の中で完結します
- 新しい版の知らせのために、先生の画面が GitHub Pages の `version.json`（版の番号と変更点だけの公開ファイル）を読みに行きます。学校のデータは送りません

## だれが何を見られるか
- 部員：全員の日誌とコメントを見られます。書けるのは自分の欄と、コメント・全体の予定・自分の班の締切だけです
- 先生（部員シートで区分が「教員」の人と、管理者メールの人）：すべての欄を直せます
- 部員の画面には、ほかの人のメールアドレスを出しません。ハコ日誌DB へのリンクも、先生にだけ出します
- 学校のアカウントで、部員シートにない人が開いたときは、見るだけになります

## 安全のための確認
先生がアプリを開いたときに、次のことを確かめ、問題があれば先生の画面に出します（6時間ごとに確かめ直します。「🔄 もう一度確かめる」ですぐ確かめ直せます）。
- ハコ日誌DB が、学校の全員やリンクを知っている人に公開されていないか
- ハコ日誌DB を、生徒や先生以外の人と共有していないか
- 活動予定表が開けるか、部員が開けるようになっているか
- 活動日の自動の読み込みが設定されているか

共有ドライブに置いたときは、共有ドライブのメンバーまでは確かめられないことがあります。**先生だけがメンバーの共有ドライブ**に置いてください。

## 消すとき
- 卒業・退部のときは、部員シートの「在籍」の ✓ を外します。記録は残ります
- 記録を完全に消すときは、先生がハコ日誌DB のシートの行を消します
- コメントの「削除」は、画面から見えなくするだけで、記録はシートに残ります

## 引き継ぎ
アプリは、公開した先生のアカウントの権限で動きます。異動や退職の前に、引き継ぐ先生がハコ日誌DB のオーナー（または先生だけの共有ドライブのメンバー）になり、アプリを公開し直してください（アプリの URL は変わります）。先生だけの共有ドライブに置いておくと、引き継ぎがかんたんです。
