# 4. 活動予定表

活動予定表は、初期設定で作られるスプレッドシートです。3つのシートがあります。

| シート | 説明 |
|---|---|
| **年間予定** | 4月〜3月の1日1行。**ここだけ入力すればよい**（アプリはここから活動日を読みます） |
| 祝日 | その年度の祝日（計算で入れています） |
| 月予定 | 年間予定から2か月分を表示する、印刷用のシート |

## 年間予定の書き方
| 列 | 入れるもの |
|---|---|
| 月・日・曜 | 入っています（直さない） |
| 行事（2列） | 学校行事など |
| 活動予定 | 活動があるかどうか（下の決まり） |
| 時間・活動場所・備考 | アプリの日付の下に出ます |

**活動日の決まり**
- 平日：空欄なら**活動あり**、「×」なら活動なし
- 土日・祝日：「〇」（午前）「△」（午後）「◎」（全日）があれば**活動あり**、空欄なら活動なし

土日・祝日の行には色が付きます。特別な休日（振替の休みなど）は、祝日シートに足してください。

## アプリへの反映
- 年間予定を直すと、**1時間以内に**アプリに反映されます
- 急ぐときは、ハコ日誌DB のメニュー「ハコ日誌 → 活動日を今すぐ同期」
- アプリを開いたままのときは、再読み込み（F5）

## 月予定（印刷用）
- 「月予定」シートの **F2** に月初めの日（例：2026/11/1）を入れると、その月と翌月の予定表になります
- ハコ日誌DB のメニュー「ハコ日誌 → 活動予定表の作業 → 月予定を保存」で、値だけの月のシートとして残せます（月予定の右に並びます）
- 色や文字がくずれたときは「活動予定表の作業 → 月予定の色と文字を整える」

## 置き場所
活動予定表は、部員も「📅 年間予定」から見ます。部員と使うフォルダ（部の共有ドライブなど）に置くか、部員に「閲覧者」で共有してください。**個人情報は書かないでください。**
