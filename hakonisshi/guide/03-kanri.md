# 3. ふだんの使い方と管理

## 部員
- 活動のはじめに「**予定**」、終わりに「**やったこと・振り返り**」「**次回やること**」を書く。書くと自動で保存されます
- 前回の「次回やること」は、予定の欄の下に出ます。「予定に使う」で写せます
- ほかの人の欄は見るだけです。欄を**右クリック**（Chromebook は2本指でタップ）すると、コメントを書けます
- 自分の記録にコメントが付くと、右上の 🔔 に数が出ます
- 「所属テーマ」で、自分の班を選び直せます
- 「予定」タブで、自分の班の締切・目標を登録できます（部全体の予定は先生だけ）

## 先生
- 部員の欄は、ふだんは見るだけの表示です。直すときは名前の下の「**✏️ 編集**」
- 出欠は、「編集」を押さなくてもボタンで入れられます
- 日付の下の「**全体の予定**」に、その日の班ごとの予定などを書けます（部員も書けます）
- 右上のボタン
  - 「📅 年間予定」：活動予定表を、今日の行を選んだ状態で開く（部員にも出ます）
  - 「🗂 ハコ日誌DB」：名簿などを直すときに開く（先生だけ）
  - 「🎨 アプリの表示」：アプリ名・団体名・色・リンク（下）
- 「🔗 この日のリンク」で、その日の画面を開くリンクをコピーできます（ハコチャットや Classroom に貼れます）

## テーマ（班）
- 「テーマ」タブ →「⚙ テーマを管理」（先生だけ）で、作る・名前を変える・状態（進行中・休止・完了・要確認）・表示順・色を決める
- テーマ名を変えても、これまでの記録や所属はそのまま引き継がれます
- 終わったテーマは「完了」にすると、所属テーマなどを選ぶ一覧に出なくなります（記録は残り、テーマの画面で見られます）

## アプリの表示
先生の画面の右上「🎨 アプリの表示」で変えられます。全員の画面に反映されます。

| 項目 | 説明 |
|---|---|
| アプリ名 | 画面の左上とブラウザのタブに出る名前 |
| 団体名 | アプリ名の下に小さく出る（例：〇〇中学校 科学部） |
| 色 | 上の帯の色。「標準（白）」、グラデーションと光の華やかな11色、単色の落ち着いた4色から選ぶ（ハコチャットと同じ色） |
| リンク（3つまで） | 全員の画面の上に出るリンク（例：ハコチャット、Classroom） |

## ハコチャットとつなぐ
URL を1回貼るだけで、両方の画面に、もう片方を開くリンクが出ます。アプリの URL は学校ごとに公開したときに決まるので、最初の1回だけ先生が貼ります。

**ハコ日誌の画面に「🔗 ハコチャット」を出す**
1. ハコチャットのアプリの URL（`https://script.google.com/…/exec`）をコピーする
2. ハコ日誌の先生の画面の右上「🎨 アプリの表示」→ いちばん下の「💬 ハコチャットとつなぐ」に貼り、「リンクに入れる」
3. 「保存」→ 全員の画面の右上に「🔗 ハコチャット」が出ます

**ハコチャットの画面に「🔗 ハコ日誌」を出す**
ハコチャットの「🎨 アプリの表示」の「📔 ハコ日誌とつなぐ」に、ハコ日誌のアプリの URL を貼ります（[ハコチャットの手引き](../../guide/03-kanri.md)）。ハコチャットから開いたときは、ハコ日誌の左上に「← （ハコチャットのアプリ名）に戻る」が出ます。

データの共有や、自動の投稿はしません（リンクだけです）。

## 部員の入れ替え（年度の変わり目など）
- 新しい部員：ハコ日誌DB の「部員」シートに行を足す
- 卒業・退部：「在籍」の ✓ を外す。記録は残り、個人・テーマの画面で名前も出ます
- 学年：「学年」の列を直す
- 新しい年度への切り替えのしかたは、年度末までにこの手引きに足します
