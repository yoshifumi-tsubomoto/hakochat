# 5. 新しい版への更新

新しい版が出ると、先生の画面に「新しい版 vX があります」と出ます。

Google Apps Script のしくみ上、アプリが自分で新しい版に変わることはできません。次のとおり、ファイルを貼り替えてください（10分ほど）。**データ（ハコ日誌DB のシート）はそのまま残ります。**

## 更新のしかた
1. このリポジトリの [`hakonisshi/gas/`](../gas) を開く
2. `Code.gs` を開き、右上の「Copy raw file」（コピーのボタン）を押す
3. ハコ日誌DB のメニュー「拡張機能」→「Apps Script」で、`コード.gs` の中身を**全部消してから**貼り付ける
4. 同じように、`index.html` を、エディタの `index.html` に貼り付ける
5. 変更点に「appsscript.json を変えた」とあるときだけ、`appsscript.json` も貼り付ける（プロジェクトの設定で「マニフェスト ファイルをエディタで表示する」に✓）
6. Ctrl + S で保存
7. 「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョンを「**新バージョン**」→「デプロイ」
   - **「新しいデプロイ」は使わないでください。** URL が変わってしまいます
8. 変更点に「新しい権限」とあるときは、ハコ日誌DB を開き直し、メニュー「ハコ日誌 → 活動日を今すぐ同期」を実行して、承認の画面で「許可」

## 版の番号
画面の右上に「v1.0.0 更新履歴」のように出ます。更新のあと、新しい番号になっていれば完了です。押すと、これまでの変更点が見られます。
