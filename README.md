# ハコチャット

**学校の Google アカウントで動く、部活動・クラブのためのチャット。データは学校のドライブから出ません。**

共有ドライブのフォルダを「チャンネル」にして、話題ごとにやり取りできるチャットです。外部の指導者や保護者も、先生が登録した人だけが、決められた範囲で参加できます。付属の **ハコ日誌**（部日誌）と組み合わせて使えます。

## 見る・試す

- 紹介ページ：https://yoshifumi-tsubomoto.github.io/hakochat/
- **体験版**（ログイン不要。見本のデータで、画面を触れます）：https://yoshifumi-tsubomoto.github.io/hakochat/demo/
- ハコ日誌の紹介と体験版：https://yoshifumi-tsubomoto.github.io/hakochat/hakonisshi/

## しくみ

```
GitHub（プログラムを配るだけ）
   ├─→ A校がコピー → A校の Google アカウントで動く（データは A校のドライブ）
   └─→ B校がコピー → B校の Google アカウントで動く（データは B校のドライブ）
```

- 各学校が、**自分の学校の Google アカウント**にテンプレートをコピーして使います。作者のサーバーはなく、データが作者に届くこともありません
- 学校のアカウントで動くアプリなので、**生徒は許可の画面なしで、学校のアカウントのまま使えます**（同じ学校のドメインの人は、自動で本人確認されます）
- 投稿・名簿は先生だけの共有ドライブのスプレッドシートに、添付ファイルはチャンネルのフォルダに保存します

## できること

- 共有ドライブのフォルダごとのチャンネル、スレッドと返信、すべてのチャンネルをまとめて見るストリーム
- 読んだ返信の自動の折りたたみ、投稿ごとの既読の確認、スタンプ、ピン止め、検索
- チャンネルのフォルダへのファイルの自動保存
- チャンネルの種類（生徒全員・限定メンバー・保護者にも公開・保護者のみ）
- 欠席連絡のボタンと一覧（先生・指導者だけに見えるメモ欄つき）
- 保護者へのメールのお知らせ（1日1回）
- 名簿の表からのまとめての登録・削除、アプリ名・団体名・色（10色）の設定、ほかのアプリへのリンク
- **1対1の会話の機能はありません**。先生は、すべてのチャンネルを見られます

## 使えるもの

- **学校の Google アカウント（Google Workspace for Education など）**と、**共有ドライブを2つ**（メンバーの生徒が使う「活動の共有ドライブ」と、先生だけの共有ドライブ）
- 学校外の人（指導者・保護者）を入れるときは、ログイン用のアプリもコピーします
- 学校で使うときは、**学校の情報管理のきまりに従い、管理職などに確認してから**使ってください

## 新しい版が出たら

管理者の画面の左下に、版の番号と「🆕 新しい版があります」が出ます。変更点を確かめて、[更新のしかた](guide/05-koushin.md) のとおり、ファイルを貼り替えてください。Google Apps Script のしくみ上、自動では更新されません。
