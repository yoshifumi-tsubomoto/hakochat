# 3. 準備と毎日の管理

管理者の先生は、左の一覧の下の「⚙ 管理」から設定します。

## メンバー（👥 メンバー）
- **1人ずつ**：「＋ メンバーを追加」。区分（生徒・指導者・保護者・管理者）を選びます
- **表からまとめて**：「📋 表からまとめて追加」。スプレッドシートの表をコピーして貼り付け、「確かめる」→「登録する」。1行でも問題があれば、どの行も登録しません

  | 表示名 | メールアドレス | 区分 | 学年 | 子ども | 通知の送り先 |
  |---|---|---|---|---|---|
  | 山田 太郎 | （学校のアドレス） | 生徒 | 2 | | |
  | 山田 太郎 母 | （Google アカウント） | 保護者 | | 山田 太郎 | （空でよい） |

- **名簿から削除**：卒業・退会のとき。1人ずつは「編集」→「名簿から削除」、まとめては名簿の左の □ で選んで「選んだ人を名簿から削除」。過去の投稿は「（退会したメンバー）」として残ります
- **停止**：一時的に使えなくするときは「編集」→ 状態を「停止」
- 生徒には、招待のメールは送りません。登録すれば、そのまま使えます。途中から入った人には、登録より前の投稿は既読として表示されます

## チャンネル（# チャンネル）
活動の共有ドライブと、先生だけの共有ドライブの**すぐ下のフォルダ**が、チャンネルの候補として並びます（フォルダ名の先頭の番号で並びます）。

| 種類 | 見られる人 |
|---|---|
| 生徒全員 | 先生・指導者・生徒全員 |
| 限定メンバー | 先生・指導者・選んだ生徒（「選ぶ」で決める） |
| 保護者にも公開 | 生徒全員と保護者全員 |
| 保護者のみ | 先生・指導者・保護者（生徒は見られない）。**先生だけの共有ドライブのフォルダにしか設定できません** |
| チャンネルにしない | 一覧に出さない |

- **欠席連絡用**：✓を入れたチャンネルに「📝 欠席連絡」のボタンが出ます。生徒用と保護者用に1つずつがおすすめです
- 活動の共有ドライブのファイルは、生徒がドライブから直接見られます。隠したいファイルを扱うチャンネルは、先生だけの共有ドライブに作ってください
- 「＋ 新しいチャンネル」で、フォルダごと作れます。ドライブで直接作ったフォルダは「ドライブを読み直す」で並びます
- フォルダを消すと「フォルダが見つかりません」と出ます。「🗑 一覧から消す」で一覧から外せます

## 欠席連絡の一覧（📝 欠席連絡の一覧）
直近2週間の欠席・遅刻・早退が、日付の順に並びます。先生・指導者へのメモも見られます。先生が電話などで受けた連絡を、代わりに登録することもできます。

## アプリの表示（🔔 通知・ログイン → 🎨 アプリの表示）
- アプリ名・団体名・色（10色）
- **リンク**：名前と URL を3つまで。左の一覧の下に「🔗 名前」で全員に出ます

## ハコ日誌とつなぐ
ハコチャットとハコ日誌は、学校ごとに別々に公開するので、**最初はつながっていません**（アプリの URL は、公開したときに初めて決まるためです）。両方を公開したあと、次のようにつなぎます（1分ほど）。

1. ハコ日誌を公開したときの「ウェブアプリの URL」（`https://script.google.com/…/exec`）をコピーする
   - あとから確かめるときは、ハコ日誌のエディタで「デプロイ」→「デプロイを管理」
2. ハコチャットの「⚙ 管理 → 🔔 通知・ログイン → 🎨 アプリの表示」で、「**📔 ハコ日誌とつなぐ**」を押す
3. 出てきた欄に、1. の URL を貼って「OK」
   - リンクの欄に、名前「ハコ日誌」と、戻り先（ハコチャットの URL と名前）を付けた URL が入ります
4. 「**保存**」を押す

これで、ハコチャットの左の一覧の下に「🔗 ハコ日誌」が出ます。押すとハコ日誌が開き、ハコ日誌の左上に「← （ハコチャットのアプリ名）に戻る」が出ます。

- ハコ日誌の側からも、いつでもハコチャットを開けるようにするには、ハコ日誌の先生の画面の右上「🎨 アプリの表示」で「💬 ハコチャットとつなぐ」を押し、ハコチャットの URL を貼って保存します。全員の画面の右上に「🔗 ハコチャット」が出ます（[ハコ日誌の手引き：ハコチャットとつなぐ](../hakonisshi/guide/03-kanri.md#ハコチャットとつなぐ)）
- アプリ名を変えたときは、「📔 ハコ日誌とつなぐ」をもう一度押して保存すると、「戻る」の表示も新しい名前になります

## 保護者へのお知らせ（🔔 通知・ログイン）
時刻を選んで「毎日の通知を始める」。新しい投稿があった日だけ、保護者に1日1回メールを送ります（本文は各投稿の最初の50文字まで。先生・指導者へのメモは載せません）。
