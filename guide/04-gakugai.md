# 4. 学校外の人を入れる（必要なときだけ）

外部の指導者や保護者は、学校のドメインのアカウントを持っていません。本人を確かめるために、**ログイン用アプリ**をもう1つ公開します。学校の中の人（先生・生徒）だけで使うなら、この章は不要です。

## 1. ログイン用アプリをコピーして公開する
1. [ログイン用のテンプレート](（公開時に入れます）) を、学校のアカウントで開き、ⓘ（概要）→「コピーを作成」
2. コピーを、本体と同じ先生だけの共有ドライブに移す
3. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」
   - 次のユーザーとして実行：**ウェブアプリにアクセスしているユーザー**
   - アクセスできるユーザー：**Google アカウントを持つ全員**
4. 出てきた URL（`…/exec`）を控える（＝ログイン用のURL）

## 2. 本体とつなぐ
1. 本体の「デプロイを管理」で、アクセスできるユーザーが「**Google アカウントを持つ全員**」になっていることを確かめる
2. 本体の「⚙ 管理 → 🔔 通知・ログイン」で、「ログイン用アプリのURL」にログイン用のURLを入れて「保存」
3. 同じ画面の表に、ログイン用アプリに入れる値が出ます（合言葉は「合言葉を表示する」を押すと出ます）。ログイン用アプリの「プロジェクトの設定（歯車）→ スクリプト プロパティ」に、次を入れる

   | プロパティ | 値 |
   |---|---|
   | `MAIN_URL` | 表の MAIN_URL（本体のアプリのURL） |
   | `SHARED_SECRET` | 表の SHARED_SECRET（合言葉。**メールやチャットに書かないでください**） |
   | `APP_NAME` | 本体のアプリ名（なくてもよい） |

## 3. 外部の人が初めて開くとき
- 「Google アカウントでログイン（学校外の方）」を押し、Google の許可の画面で許可します。求めるのは**メールアドレスの参照だけ**です（ドライブやメールを見る権限は求めません）
- 「Google で確認されていません」と出ることがあります。案内に、画面の写真を付けておくと安心です
- 画面の上に「このアプリケーションは Google Apps Script のユーザーによって作成されたものです」という帯が出ます（Google が付けるもので、消せません）。右端の × で閉じ、帯の中のリンクは押さないよう案内してください
- 一度ログインすると、そのブラウザでは30日間ログインしたままになります

## 4. 登録
外部の人も、先にメンバーとして登録します（Google アカウントのアドレス）。保護者は「子ども」と、メールのお知らせの送り先（ふだん読んでいるアドレスが別なら）を入れます。

## 注意
- 指導者は、すべてのチャンネル（保護者のみ・欠席連絡のメモを含む）を見られます
- 保護者向けのフォルダを共有すると、Google ドライブの共有の画面で、同じフォルダを共有された人どうしのアドレスが見える場合があります。保護者に説明するときは、この点も伝えてください
