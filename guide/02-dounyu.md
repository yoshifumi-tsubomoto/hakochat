# 2. 導入（30分ほど）

**すべて、学校の Google アカウントで行います。** 個人のアカウントでは、生徒が使えません。

## 1. テンプレートをコピーする
1. [ハコチャットのテンプレート](https://script.google.com/d/17nBVqAu_2ARac0cFdpw30vSRXV9D5NtFf_Foanbm0jXm4zcLUWuARDhe/edit?usp=sharing) を開く
2. 左の ⓘ（概要）→ 右上の「コピーを作成」
3. コピーの名前を変える（例：`ハコチャット_本番`）
4. Google ドライブで、コピーを**先生だけの共有ドライブ**に移す
   - マイドライブに置いたままだと、先生の異動や退職のときに引き継ぎにくくなります

## 2. 権限を許可する
1. コピーのエディタで、上の関数の欄から `authorizeAll` を選び、「▷実行」
2. 許可を求められたら、内容を確かめて許可する
   - 「Google で確認されていません」と出たときは、作成者が自分になっているのを確かめて「詳細」→「（プロジェクト名）に移動」
3. 実行ログに「必要な権限は許可されています」と出れば完了です

求める権限：ドライブ（チャンネルのフォルダとデータ）、スプレッドシート、メールの送信（保護者へのお知らせ）、時刻の予約（毎日のお知らせ）、メールアドレスの参照（本人確認）

## 3. 公開する
1. 「デプロイ」→「新しいデプロイ」→ 種類の歯車で「ウェブアプリ」
2. 次のユーザーとして実行：**自分**
3. アクセスできるユーザー：
   - 学校の中の人だけで使う → **（学校のドメイン）内の全員**
   - 外部の指導者・保護者も入れる → **Google アカウントを持つ全員**（[4. 学校外の人を入れる](04-gakugai.md) も行う）
4. 「デプロイ」→ 出てきた URL（`…/exec`）を控える。これが**アプリのURL**です

## 4. 準備の画面
アプリのURLを開くと、「準備」の画面が出ます（最初の1回だけ。公開した先生だけに出ます）。

| 欄 | 入れるもの |
|---|---|
| アプリ名 | 画面に出す名前（例：〇〇中 科学部チャット）。あとで変えられます |
| 団体名 | 学校名や部の名前（なくてもよい） |
| 色 | 15色から選ぶ（華やかな11色と、落ち着いた4色） |
| 活動の共有ドライブ | チャンネルにするフォルダが並ぶ共有ドライブの URL か ID |
| 先生だけの共有ドライブ | データを置く、先生だけがメンバーの共有ドライブの URL か ID |
| あなたの表示名 | 例：山田先生 |

「準備する」を押すと、先生だけの共有ドライブにデータのスプレッドシートができ、活動の共有ドライブのフォルダが「チャンネルにしない」で並びます。

## 5. 使い始める
1. [3. 準備と毎日の管理](03-kanri.md) のとおり、チャンネルの種類を決め、メンバーを登録する
2. アプリのURLを、Classroom などで生徒に知らせる

## うまくいかないとき
- URL に `/u/1/` などが付いて「ファイルを開くことができません」と出る → ブラウザに複数のアカウントでログインしているためです。アドレス欄から `u/1/` を消して開き直してください
- 「まだ準備ができていません」と出る → 公開した先生が、先に準備の画面で「準備する」を押してください
