# 6. データと個人情報

管理職や情報担当の先生に説明するときに使ってください。

## どこに何が保存されるか
| データ | 置き場所 |
|---|---|
| 名簿（名前・メールアドレス・区分・学年）、投稿、既読、スタンプ、欠席連絡とメモ | 先生だけの共有ドライブのスプレッドシート |
| 添付ファイル | チャンネルのフォルダの中の「チャット添付」フォルダ |
| アプリの設定（アプリ名・色・合言葉など） | アプリのスクリプト プロパティ |

- **作者や外部のサーバーには、データを送りません。** 動作は、学校の Google の環境の中で完結します
- 例外：保護者へのお知らせのメールに、投稿の最初の50文字が入ります（保護者のメールアドレスあて）
- 新しい版の知らせのために、管理者の画面が GitHub Pages の `version.json`（版の番号と変更点だけの公開ファイル）を読みに行きます。学校のデータは送りません

## だれが何を見られるか
- 先生（管理者）と指導者は、すべてのチャンネルを見られます。**1対1の会話の機能はありません**
- 生徒は、見られるチャンネルの投稿だけを受け取ります。見られないチャンネルのデータは、生徒の画面に送りません
- 保護者には、既読の「人数」だけを見せ、だれが読んだかは見せません。ほかの人のメールアドレスは、どの画面にも出しません
- 欠席連絡の「先生・指導者へのメモ」は、本人と先生・指導者だけが見られます
- 活動の共有ドライブにあるファイルは、共有ドライブのメンバーの生徒がドライブから直接見られます（アプリで隠しても見えます）

## 消すとき
- 卒業・退会のときは「名簿から削除」で、名前とメールアドレスが消え、フォルダの共有も外れます。過去の投稿は「（退会したメンバー）」として残ります
- 投稿の「削除」は、画面から見えなくするだけで、記録はスプレッドシートに残ります（トラブルのときに確かめられるように）。完全に消すときは、管理者がスプレッドシートの行を消します

## 引き継ぎ
アプリは、公開した先生のアカウントの権限で動きます。異動や退職の前に、別の先生がアプリを公開し直す必要があります。アプリとデータを先生だけの共有ドライブに置き、引き継ぐ先生もその共有ドライブのメンバーにしておいてください。
