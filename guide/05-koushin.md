# 5. 新しい版への更新

新しい版が出ると、管理者の画面の左下に「🆕 新しい版があります」と出ます。押すと、変更点が見られます。

Google Apps Script のしくみ上、アプリが自分で新しい版に変わることはできません。次のとおり、ファイルを貼り替えてください（10分ほど）。**データ（スプレッドシート）はそのまま残ります。**

## 本体の更新
1. このリポジトリの [`gas/hakochat/`](../gas/hakochat) を開く
2. `Code.gs` を開き、右上の「Copy raw file」（コピーのボタン）を押す
3. 自分のアプリのエディタで、`コード.gs`（または `Code.gs`）の中身を**全部消してから**貼り付ける
4. 同じように、`index.html` を、エディタの `index` に貼り付ける
5. 変更点に「appsscript.json を変えた」とあるときだけ、`appsscript.json` も貼り付ける（プロジェクトの設定で「マニフェスト ファイルをエディタで表示する」に✓）
6. Ctrl + S で保存
7. 「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョンを「**新バージョン**」→「デプロイ」
   - **「新しいデプロイ」は使わないでください。** URL が変わってしまいます
8. 変更点に「新しい権限」とあるときは、`authorizeAll` をもう一度実行して許可する

## ログイン用アプリの更新
変更点に「ログイン用」とあるときだけ、[`gas/hakochat-login/`](../gas/hakochat-login) の `Code.gs` と `bridge.html` を同じように貼り替え、新バージョンでデプロイします。

## 版の番号
管理者の画面の左下に「版 1.0.0」のように出ます。更新のあと、新しい番号になっていれば完了です。

[version.json](https://yoshifumi-tsubomoto.github.io/hakochat/version.json) に、版ごとの変更点があります。
